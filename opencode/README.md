- opencode finds SKILLS
- SKILL.md can be found in many directories

- ~/.config/opencode/skills  <- place opencode prefers, a skill her overrides skill with same name elsewhere
- ~/.agents/skills/     <- npx uses this;  standardized location that other AI agents may use


- to find a skill:
find <dir> -NAME  <myskill.md>

- to remove
sudo rm -rf  <myskill>
