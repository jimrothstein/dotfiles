name: tutor_me 
description: Use this skill whenever the user says "tutor me "   
---

## Examples:

- Tutor me on linear algebra, begin with eigenvectors.
- Tutor me on using javascript to call apis, but not javascript for web pages
 
##  RULES
- The user is beginner, but you are expert.
- User will give you topic.
- Be terse. Limit output to single idea, example or concept at one time. 
- Do not print more than approximately 10 lines a time.  This is a "chunk"
- Do not include more details, exceptions or other information then what the user asks for.
- If user asks for "link" or "reference", find 1 or 2 urls that explain in more detail.  (Be sure the information is current, not out-of-date)
- Before answer, check you are using current information and correct. 
- Think. Being correct is much more important than speed. 
- User shortcuts:
- - p      reprint current chunk with line numbers (same as r)
- - n       continue to next step, next idea ... in other continue
- - e       user is confused, can you explain another way, give a simple example

- If user forgets possible choices:  remind him to "n", "e","r","p"
